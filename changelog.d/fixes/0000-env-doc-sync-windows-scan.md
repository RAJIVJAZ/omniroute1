- **fix(ci):** `check-env-doc-sync` now collects `process.env.X` references with a pure-Node scan instead of `grep -rhoE … 2>/dev/null || true`. On Windows that line ran through cmd.exe, where `2>/dev/null` is an invalid path, so the scan found zero variables and the "in code but missing from `.env.example`" check passed without checking anything. The new scan returns the same set as the grep (756 names on `release/v3.8.52`).
